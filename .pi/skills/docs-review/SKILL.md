# Documentation Review

1. Compare `README.md` and inline code comments with the current code.
2. Compare installation documentation with the most recent Git tag.
3. Correct any discrepancies you find.
4. If changes are needed in GitHub Actions, create a pull request containing only the necessary documentation updates. If the documentation is already accurate, make no changes.
